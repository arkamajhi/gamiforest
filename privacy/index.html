Data used by this website

The static GamiForest website does not require accounts, use an analytics service, or set advertising cookies. Interactive searches and the forest compass run in your browser. A local favorite or explored-state preference, when enabled, stays in browser storage and is not transmitted to us.

We use externally hosted Google Fonts and Unsplash imagery on the homepage, so those providers may receive typical connection information such as your IP address. Linked external sites have their own privacy policies.

Submissions

The contribution form opens your own email client using a mailto link. It does not transmit form content to a GamiForest web server. Submissions are sent only if you choose to send the email from your mail application.

Updates

This description reflects the initial static website. Review and update it if you add analytics, embedded services, accounts or a live submission backend.
